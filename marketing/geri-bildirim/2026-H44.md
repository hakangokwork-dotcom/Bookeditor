## Discussions (github.com/hakangokwork-dotcom/Bookeditor/discussions)

**Bu hafta da erişilemedi.** Bu oturumda GitHub erişimi GitHub MCP
sunucusu üzerinden sağlanıyor; sunucunun araç setinde (issue/PR
araçları — `list_issues`, `search_issues`, `pull_request_read` vb.)
Discussions için bir uç nokta yok. `gh` CLI'ye bu oturumdan doğrudan
erişim de kapalı, dolayısıyla `gh api repos/.../discussions` komutu
geçen hafta olduğu gibi bu hafta da çalıştırılamadı.

**Öneri (geçen haftadan değişmedi):** Repo sahibi isterse GitHub
Discussions sekmesini elle kontrol edebilir. Bu nöbetin Discussions
kısmının otomatik çalışabilmesi için oturuma Discussions GraphQL
desteği olan bir erişim yolu eklenmesi gerekir.
