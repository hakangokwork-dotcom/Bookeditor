# OKUBENI — marketing/ Kullanım Kılavuzu

Bu klasördeki her şey kopyala-yapıştır hazırdır; her parçanın başında nereye ve
nasıl gönderileceği yazar. Tüm metinler site çevirileri (en.json / tr.json) ve
uygulama koduyla çapraz doğrulanmıştır: uydurma rakam, kullanıcı yorumu ve
olmayan özellik yoktur.

## Hangi dosya ne?

| Dosya | İçerik | Ne zaman |
|---|---|---|
| **lansman-kiti.md** | Product Hunt (isim, tagline, 260 karakterlik açıklama, ilk yorum, galeri planı) · Show HN (başlık, gönderi, 5 sert soruya hazır cevap) · GitHub README vitrini taslağı + rozetler | Tek seferlik: lansman haftası |
| **topluluk-ve-dm.md** | Mikro-influencer DM şablonları (TR+EN) ve hedef bulma kriterleri · Reddit planı (2-3 hafta ısınma + gönderi) · Ekşi Sözlük girişleri · GitHub Discussions karşılama + yol haritası gönderileri | Zemin işleri: lansmandan ÖNCE başlar |
| **sosyal-takvim.md** | 4 haftalık takvim: LinkedIn (Salı) + X (Pzt/Çar/Cum), 16 hazır gönderi + 2 kısa video senaryosu | Süreklilik: lansmanla birlikte döner |

## Sıra (önerilen)

**Hafta 0 — hazırlık (bir kez, ~1-2 saat):**
1. GitHub Discussions'a 2 sabit gönderi (topluluk-ve-dm §4) — 10 dk, hemen yapılabilir.
2. Ekran görüntüsü setini bir kez çekin (lansman-kiti §1.5'teki 6 kare): PH galerisi,
   README ve sosyal gönderiler aynı setten beslenir. Kişisel kitap verisi görünmesin;
   örnek içerik "Slow Cities" olabilir.
3. README vitrinini yayına alın (lansman-kiti §3; önce LICENSE ve macOS release
   adlarını §3.3 listesinden kontrol edin).
4. Shopier destek bağlantısını canlıya alıp test edin — kahve temalı içerikler
   (X-12, PH/HN metinlerindeki destek linki) bundan önce sorun çıkarabilir.
5. Reddit ısınmasına başlayın (topluluk-ve-dm §2a: günde 10-15 dk, link atmadan).

**Hafta 1-4 — döngü:** sosyal-takvim.md'yi takip edin; paralelde haftada 3-5
kişiselleştirilmiş DM (topluluk-ve-dm §1).

**Hafta 2-3 — lansman günü:** README + site + görseller hazırken Show HN ve
Product Hunt (aynı gün şart değil; ikisinde de gün boyu yorumlara dönmek için
boş bir gün seçin — hazır cevaplar lansman-kiti §2.3'te).

**Hafta 3-4:** Reddit gönderisi (ısınma tamamlanınca). Ekşi Sözlük girişi
acele değil; §3'teki dürüstlük notuna uyarak uygun zamanda.

## Haftalık ritim (~20 dk kopyala-yapıştır)

- **Pazar veya Pazartesi, 10-12 dk:** o haftanın 4 gönderisini (1 LinkedIn + 3 X)
  takvimden kopyalayın, görselini yanına koyun, zamanlayın veya günü gelince atın.
- **Hafta içi serpiştirilmiş 5-8 dk:** gelen yorum ve DM cevapları. Ton hep aynı:
  sakin, teşekkür eden, savunmasız.
- Video haftalarında (2. ve 4. hafta) +30-45 dk çekim — senaryolar tablo halinde hazır.

## Değişmez kurallar (tüm dosyalar bunlara göre denetlendi)

- Kurucu adı hiçbir metinde geçmez; ürün-sesli yazılır ("inkGuide", gerekirse "geliştiricisi").
  Tek istisna Reddit: platform gereği "ben" dili, ama isimsiz.
- Uydurma rakam, indirme sayısı, kullanıcı yorumu yok — gerçek veri olana kadar.
- Dikte istisnası (ses, tarayıcı üreticisinin sunucusuna gider) sesli notla ilgili
  her içerikte açık kalır.
- Pazarlama klişesi yok ("devrim", "oyun değiştirici" vb. yasak).
- Sahte kullanıcı rolü yok: Ekşi/Reddit'te geliştirici kimliği sorulursa gizlenmez.
