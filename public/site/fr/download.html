Télécharger inkGuide

Téléchargez, ouvrez, écrivez. Sans compte, sans inscription ; internet ne sert qu'au téléchargement lui-même. Votre livre grandit sur votre propre ordinateur.

Installez-le sur votre ordinateur

Un seul fichier, pas d'installateur : téléchargez, double-cliquez, écrivez. Il fonctionne aussi hors connexion ; la version macOS est en chemin.

Télécharger pour Windows inkGuide.exe · v1.0.0 · 64 Mo · fichier portable unique · Windows 10+ Le téléchargement démarre aussitôt ↓
Télécharger pour macOS macOS 12+ · ~24 Mo · décompressez puis double-cliquez Apple Silicon (M1–M4) ↓ Intel ↓ Premier lancement : clic droit → Ouvrir (app non signée)
iPhone, iPad ou Android ? Rien à installer — ouvrez inkGuide sur votre ordinateur, cliquez sur le bouton Téléphone et scannez le code QR : votre appareil devient un compagnon de capture en Wi-Fi.

Configuration requise

  • Windows 10 ou plus récent — pas d'installateur, pas de logiciel supplémentaire
  • Un navigateur moderne (Chrome ou Edge ; nécessaire pour la dictée vocale)
  • Environ 150 Mo d'espace disque ; une connexion internet uniquement pour le téléchargement
  • Vos données vivent dans le dossier data/ à côté de l'exe — déplacez le dossier et elles suivent
Un avertissement de Windows peut apparaître au premier lancement.
inkGuide étant une application récente et non signée, Windows SmartScreen peut afficher un avertissement bleu. Choisissez « Informations complémentaires » → « Exécuter quand même » — l'application est open source, tout son code peut être inspecté sur GitHub, et elle n'envoie aucune donnée depuis votre ordinateur. Si vous préférez, vous pouvez aussi la lancer depuis le code source (inkGuide.bat dans le dépôt).

Vos trois premiers pas après l'installation

01

Lancez-la et nommez votre livre

Double-cliquez sur inkGuide.exe ; l'espace de travail s'ouvre de lui-même dans votre navigateur. Dans l'assistant de bienvenue, donnez à votre livre un titre provisoire — il pourra changer plus tard, il n'a pas besoin d'être parfait.

02

Esquissez le plan

Ajoutez au panneau de gauche les parties et chapitres que vous avez en tête. Trois à cinq titres suffisent largement ; le plan se corrige de lui-même à mesure que vous écrivez. Réordonner par glisser-déposer reste toujours possible.

03

Déposez la première note

Commencez par collecter, pas par écrire : une citation, une idée, un gribouillis dicté. Les notes se rassemblent sous leurs chapitres ; le livre commence à apparaître avant même que vous ne vous en rendiez compte.
