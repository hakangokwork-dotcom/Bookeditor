Herunterladen, öffnen, schreiben. Kein Konto, keine Registrierung; Internet braucht es nur für den Download selbst. Dein Buch wächst auf deinem eigenen Computer.

Bring es auf deinen Computer

Eine Datei, kein Installationsprogramm: herunterladen, doppelklicken, schreiben. Es funktioniert auch ohne Internet; die macOS-Version ist unterwegs.

Für Windows herunterladen inkGuide.exe · v1.0.0 · 64 MB · eine einzige portable Datei · Windows 10+ Der Download beginnt sofort ↓
Für macOS herunterladen macOS 12+ · ~24 MB · entpacken und doppelklicken Apple Silicon (M1–M4) ↓ Intel ↓ Erster Start: Rechtsklick → Öffnen (unsignierte App)
iPhone, iPad oder Android? Keine Installation nötig — öffnen Sie inkGuide am Computer, klicken Sie auf die Telefon-Schaltfläche und scannen Sie den QR-Code: Ihr Gerät wird zum Notiz-Begleiter über WLAN.

Systemvoraussetzungen

  • Windows 10 oder neuer — kein Installationsprogramm, keine Zusatzsoftware
  • Ein moderner Browser (Chrome oder Edge; nötig für die Spracherfassung)
  • ~150 MB Speicherplatz; eine Internetverbindung nur für den Download
  • Deine Daten wohnen im Ordner data/ neben der Exe — verschiebst du den Ordner, ziehen sie mit um
Beim ersten Start kann Windows eine Warnung zeigen.
Weil inkGuide eine frisch veröffentlichte, unsignierte Anwendung ist, kann Windows SmartScreen einen blauen Hinweis einblenden. Wähle „Weitere Informationen“ → „Trotzdem ausführen“ — die App ist Open Source, ihr gesamter Code lässt sich auf GitHub einsehen, und sie sendet keine Daten von deinem Computer. Wer mag, kann sie auch direkt aus dem Quellcode starten (inkGuide.bat im Repository).

Deine ersten drei Schritte nach der Installation

01

Starte es und gib deinem Buch einen Namen

Doppelklicke auf inkGuide.exe; der Arbeitsbereich öffnet sich von selbst in deinem Browser. Gib deinem Buch im Willkommens-Assistenten einen Arbeitstitel — er darf sich später ändern und muss nicht perfekt sein.

02

Skizziere die Gliederung

Trage die Teile und Kapitel aus deinem Kopf in die linke Spalte ein. Drei bis fünf Überschriften genügen; die Gliederung korrigiert sich beim Schreiben von selbst. Umsortieren per Ziehen geht jederzeit.

03

Hinterlass die erste Notiz

Beginne mit Sammeln, nicht mit Schreiben: ein Zitat, ein Gedanke, eine gesprochene Kritzelei. Notizen sammeln sich unter ihren Kapiteln; das Buch taucht auf, ehe du es merkst.
